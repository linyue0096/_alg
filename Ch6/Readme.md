### 什麼是 Lambda 演算（λ-Calculus）？
1. 起源與理論地位：Lambda 演算（$\lambda$-Calculus）由阿隆佐·邱奇於 1930 年代提出，是一種用函數抽象與函數套用來研究計算本質的極簡形式系統。它與圖靈機等價，共同證明了計算的可行性界限，並為現代函數式程式語言（如 Haskell、Lisp）奠定了核心基礎
2. 核心要素：純粹的 $\lambda$ 演算只由三種基本語法元件組成，不需要內建的整數、布林值或迴圈：
   * 變數：用字元表示，如 $x$
   * 函數抽象（Abstraction：定義匿名函數，如 $\lambda x. M$（接受參數 $x$，回傳主體 $M$）
   * 函數套用：呼叫函數並代入引數，如 $(M\ N)$（將引數 $N$ 傳遞給函數 $M$）
3. 計算與歸約規則：
   * $\alpha$-轉換：重命名束縛變數，例如 $\lambda x. x$ 等價於 $\lambda y. y$，主要用於消除名稱衝突
   * $\beta$-歸約：計算的核心步驟，將套用式 $((\lambda x. M)\ N)$ 中的變數 $x$ 全部替換成 $N$（記作 $[x := N]M$）
   * 正規形式：當表達式內部沒有任何可被化簡的Redex時，即為最終計算結果
4. 求值策略：
   * 本實作採用正規順序歸約，每次優先尋找「最外層、最左側」的 Redex 進行化簡
   * 根據 Church-Rosser 定理，若運算式存在正規形式，正規順序歸約保證能夠成功終止並求出解，避免過早求值導致無窮迴圈

### 程式模組與演算法架構
本直譯器由 AST 資料結構、避免捕獲的代換引擎、正規順序歸約器以及語法剖析器組成：

1. AST 定義 (`Var`, `Abs`, `App`)
   * 用物件導向建立語法樹節點，分別代表變數、抽象函數與套用運算，並實作 `__str__` 以便追蹤輸出

2. 自由變數與變數生成 (`free_vars`, `fresh_var`)
   * 遞迴計算表達式中的自由變數集合（Free Variables）
   * 若代換過程中偵測到變數名稱碰撞，自動透過 `fresh_var` 生成全新名稱（例如 $x \to x_1 \to x_2$）

3. 安全替換演算法 (`substitute`)
   * 執行 $[var\_name := replacement] expr$ 的核心代換邏輯。
   * **避免變數捕獲（Variable Capture Avoidance）**：若抽象層的參數與替換項的自由變數重名，強制執行 $\alpha$-轉換進行改名，避免自由變數意外被函數抽象層綁定

4. 單步正規歸約 (`reduce_step`, `evaluate`)
   * `reduce_step` 嚴格遵循 Normal Order 規則：
     * 若為 `App(Abs, arg)` 形式的 Redex，優先直接展開。
     * 否則依序向左子樹、右子樹、函數主體深層搜尋 Redex
   * `evaluate` 負責迴圈迭代化簡步驟並格式化印出軌跡，同時設置 50 步防護上限以防無窮遞迴

5. 語法剖析器 (`tokenize`, `Parser`)
   * 支援 `\` 與 `λ` 關鍵字，運用正則表達式進行 Lexer 分詞
   * 使用遞迴下降剖析法（Recursive Descent Parser），並自動處理套用運算式的「左結合」語意（例如 `A B C` 解析為 `((A B) C)`）。

### 測試

1. 測試 1：布林值條件選擇（IF TRUE A B => A）
* 測資：`((\x.\y.x) A) B`（利用 Church 布林值 $\text{TRUE} = \lambda x.\lambda y. x$ 進行條件分支）
* 程式碼：
```python
print("--- 測試 1：布林值條件選擇 (IF TRUE A B => A) ---")
ast1 = parse(r"((\x.\y.x) A) B")
evaluate(ast1)
```
* 輸出：
```
Step 0: (((\x.(\y.x)) A) B)
Step 1: ((\y.A) B)
Step 2: A
=> 已達正規形式 (Normal Form)！共 2 步。
```
* 學習:
  函數即邏輯：在純粹的 Lambda 演算中沒有內建的 if-else，純粹靠高階函數選擇保留第一個參數或第二個參數，即可精確模擬條件分支。

2. 測試 2：變數捕獲與 Alpha 轉換測試
* 測資：(\x.\y.x) y（將自由變數 $y$ 傳遞給內部同樣以 $y$ 命名的函數抽象）
* 程式碼：
```python
print("--- 測試 2：變數捕獲與 Alpha 轉換測試 (防止 y 被外層 capture) ---")
ast2 = parse(r"(\x.\y.x) y")
evaluate(ast2)
```
* 輸出：
```
Step 0: ((\x.(\y.x)) y)
Step 1: (\y1.y)
=> 已達正規形式 (Normal Form)！共 1 步。
```
* 學習:
  防止語意污染：若未進行 $\alpha$-轉換，直接代換會得到 $\lambda y. y$（原先外部自由的 $y$ 變成了內部綁定參數，常數函數意外退化為恆等函數）。系統自動重新命名為 $y_1$ 得到 $\lambda y_1. y$，正確守住語意一致性。

3. 測試 3：Church 數字加法運算（1 + 1 = 2）
* 測資：(\m.\n.\f.\x. m f (n f x)) (\f.\x. f x) (\f.\x. f x)
* 程式碼：
```python
print("--- 測試 3：Church 數字加法運算 (1 + 1 = 2) ---")
ast3 = parse(r"(\m.\n.\f.\x. m f (n f x)) (\f.\x. f x) (\f.\x. f x)")
evaluate(ast3)
```
* 輸出：
```
Step 0: (((\m.(\n.(\f.(\x.((m f) ((n f) x)))))) (\f.(\x.(f x)))) (\f.(\x.(f x))))
Step 1: ((\n.(\f.(\x.(((\f.(\x.(f x))) f) ((n f) x))))) (\f.(\x.(f x))))
Step 2: (\f.(\x.(((\f.(\x.(f x))) f) (((\f.(\x.(f x))) f) x))))
Step 3: (\f.(\x.((\x.(f x)) (((\f.(\x.(f x))) f) x))))
Step 4: (\f.(\x.(f (((\f.(\x.(f x))) f) x))))
Step 5: (\f.(\x.(f ((\x.(f x)) x))))
Step 6: (\f.(\x.(f (f x))))
=> 已達正規形式 (Normal Form)！共 6 步。
```
* 學習:
  1. 正規順序逐步拆解：前兩步代入 $m$ 與 $n$，分別將兩個 ONE 填入加法器
  2. 第 3 至 4 步先化簡最外層最左側的第一個 (\f.\x. f x) f，展開並替換出外層的 f
  3. 第 5 至 6 步深入運算式內部化簡第二個套用項，完成內層的 (f x)
  4. 最終化簡結果為 (\f.(\x.(f (f x))))，即連續套用兩次函數 $f$，精準吻合邱奇數 $2$ 的定義。

3. Church 數字乘法運算（2 * 2 = 4）
* 測資：(\m.\n.\f. m (n f)) (\f.\x. f (f x)) (\f.\x. f (f x))
* 程式碼：
```python
print("--- 測試 4：Church 數字乘法運算 (2 * 2 = 4) ---")
ast4 = parse(r"(\m.\n.\f. m (n f)) (\f.\x. f (f x)) (\f.\x. f (f x))")
evaluate(ast4)
```
* 輸出：
```
Step 0: (((\m.(\n.(\f.(m (n f))))) (\f.(\x.(f (f x))))) (\f.(\x.(f (f x)))))
Step 1: ((\n.(\f.((\f.(\x.(f (f x)))) (n f)))) (\f.(\x.(f (f x)))))
Step 2: (\f.((\f.(\x.(f (f x)))) ((\f.(\x.(f (f x)))) f)))
Step 3: (\f.(\x.(((\f.(\x.(f (f x)))) f) (((\f.(\x.(f (f x)))) f) x))))
Step 4: (\f.(\x.((\x.(f (f x))) (((\f.(\x.(f (f x)))) f) x))))
Step 5: (\f.(\x.(f (f (((\f.(\x.(f (f x)))) f) x)))))
Step 6: (\f.(\x.(f (f ((\x.(f (f x))) x)))))
Step 7: (\f.(\x.(f (f (f (f x))))))
=> 已達正規形式 (Normal Form)！共 7 步。
```
* 學習:
  高階函數複合的力量：乘法為函數複合運算（將套用兩次的動作再重複套用兩次）。經過 7 步正規順序推演，最終式為 (f (f (f (f x))))（連續套用 4 次），展示了語法樹多層巢狀替換的正確性
