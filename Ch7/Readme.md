### 什麼是檔案差異比對 (Diff)？
1. 檔案差異比對是版本控制系統（如 Git）中用來找出兩份文件變更的核心演算法。本質上是尋找「最短編輯腳本（Shortest Edit Script, SES）」，它與「最長公共子序列（Longest Common Subsequence, LCS）」為對偶問題
2. 核心目標：給定序列 $A$（長度 $N$）與序列 $B$（長度 $M$），求出由 $A$ 轉換至 $B$ 所需的最少刪除與插入操作步數（編輯距離 $D$）。若使用傳統動態規劃（LCS），時間複雜度固定為 $O(NM)$，當比對巨型檔案時容易耗盡記憶體與時間；而邁爾斯演算法（Myers Diff）時間複雜度為 $O((N+M)D)$，且能直接在對角線上貪婪前進
3. 判定結果：
- MATCHED（完全相同）：兩檔案內容一致，無任何編輯差異（$D = 0$）
- EDITED / FOUND_DIFF（比對成功）：在可接受步數內找出最少操作數的差異路徑，依序輸出保留、刪除（`-`）與新增（`+`）
4. 編輯圖表示與走訪規則：
- 將比對問題抽象化為 $N \times M$ 的編輯圖（Edit Graph），起點為 $(0, 0)$，終點為 $(N, M)$
- 向右走一步：刪除 $A$ 中的元素（`-`），成本為 1
- 向下走一步：新增 $B$ 中的元素（`+`），成本為 1
- 沿對角線（斜右下）走：兩字元相同，成本為 0（稱為 Snake）
5. 關鍵特色（輸出敏感度）：
- 動態規劃法（LCS）：不論差異大小，都必須無差別填滿整個 $N \times M$ 的二維矩陣，對相似度極高的文字檔極為浪費
- 邁爾斯演算法（Myers）：利用 BFS 依編輯距離 $D = 0, 1, 2, \dots$ 逐層搜尋，並在字元相同時貪婪狂奔。當兩檔案差異極小（$D \ll N$）時，速度接近線性時間 $O(N+M)$
6. 收斂與效果保證：兩者皆保證能產出全域最佳的最短編輯距離；但 Myers 演算法能自然群聚差異區塊並優先執行刪除，產生的 Diff 結果最符合人類閱讀直覺

### 程式模組與演算法架構
Diff 求解器主要由四個模組組成：

1. check_identical(A, B)（快速一致性檢查）
比對前先檢驗兩序列是否長度相同且內容一致。若完全相同則直接標記為未變更，省略後續圖形搜尋或矩陣建構

2. diff_dp(A, B)（動態規劃求解模組）
建立 $(N+1) \times (M+1)$ 的 DP 表格：
- 遍歷 $A$ 與 $B$，若 $A[i-1] == B[j-1]$ 則 `dp[i][j] = dp[i-1][j-1] + 1`；否則取相鄰最大值
- 從 `dp[N][M]` 依序回溯：向左表示新增（`+`），向上表示刪除（`-`），左上表示相同字元保留
- 地雷點：回溯時若未處理邊界索引或順序顛倒，會導致產生的 Diff 標籤錯位

3. diff_myers(A, B)（Myers 廣度優先與貪婪模組）
定義對角線參數 $k = x - y$：
- 外層迴圈遞增編輯距離 $D$（每步成本為 1）
- 內層遍歷各條對角線 $k \in [-D, D]$，比較由 $k-1$（向右）或 $k+1$（向下）出發何者能走得更遠
- 貪婪滑動（Snake）：若 $A[x] == B[y]$，無成本沿對角線滑行至底
- 當任意節點抵達終點 $(N, M)$ 時立刻中斷搜尋並記錄軌跡

4. backtrack_myers(trace, A, B)（Myers 回溯路徑）
沿著記錄的對角線歷史軌跡，由 $D$ 倒推回 0，依序萃取出對角線相同字元與橫縱向的增刪動作，重構出人類易讀的統一差異清單

### 測試
1. 測試 1：標準字串交錯比對（驗證 LCS 與 Myers 編輯腳本正確性）
- 測資：
$$A = [\text{"A"}, \text{"B"}, \text{"C"}, \text{"A"}, \text{"B"}, \text{"B"}, \text{"A"}]$$
$$B = [\text{"C"}, \text{"B"}, \text{"A"}, \text{"B"}, \text{"A"}, \text{"C"}]$$
- 程式碼：
```python
print("--- 測試 1：標準字串交錯比對 [預期：成功求得最短編輯距離 D=5] ---")
A1 = ["A", "B", "C", "A", "B", "B", "A"]
B1 = ["C", "B", "A", "B", "A", "C"]
print("[LCS DP 結果]")
print("\n".join(diff_dp(A1, B1)))
print("[Myers 結果]")
print("\n".join(diff_myers(A1, B1)))
```

- 輸出：
```

[LCS DP 結果]
- A
- B
  C
+ B
  A
  B
- B
  A
+ C
[Myers 結果]
- A
- B
  C
+ B
  A
  B
- B
  A
+ C
```
- 學習:
    - 兩者等價性：兩演算法在最終編輯步數上完全一致（均為 3 次刪除、2 次新增，總成本 $D=5$），證實 LCS 與 SES 的對偶性
    - 計算量差異：LCS DP 不論如何都必須填滿 $8 \times 7 = 56$ 個矩陣節點；Myers 演算法在 $D=5$ 時即抵達終點退出，探索範圍明顯較小

2. 測試 2：巨量相似檔案微幅修改（驗證 Myers 輸出敏感性優勢）
- 測資：包含 1000 行的檔案，僅修改其中第 500 行
- 程式碼：
```python
print("--- 測試 2：1000 行檔案微幅修改 [預期：Myers 極速收斂，DP 耗時] ---")
A2 = [f"line_{i}" for i in range(1000)]
B2 = list(A2)
B2[500] = "line_500_modified"

diff_res = diff_myers(A2, B2)
print("狀態: CONVERGED (比對完成)")
print(f"差異行數: {len([x for x in diff_res if x.startswith(('+', '-'))])}")
```

- 輸出：
```
--- 測試 2：1000 行檔案微幅修改 [預期：Myers 極速收斂，DP 耗時] ---
狀態: CONVERGED (比對完成)
差異行數: 2
```
- 學習:
    - 輸出敏感優勢：此案例編輯距離僅為 $D = 2$（1 刪 1 增）。LCS DP 仍需完成 $1000 \times 1000 = 10^6$ 次迴圈運算；而 Myers 演算法只要在 $D \le 2$ 範圍內搜尋，剩餘 999 行全靠成本為 0 的對角線直接滑過，運算次數少於 100 

3. 測試 3：完全無交集的極端邊界測試
- 測資：兩份完全無重疊內容的序列（$A = [\text{"A"}, \text{"B"}], B = [\text{"C"}, \text{"D"}]$）
- 程式碼：
```python
print("--- 測試 3：完全相異內容測試 [預期：最差情況退化] ---")
A3 = ["A", "B"]
B3 = ["C", "D"]
print("\n".join(diff_myers(A3, B3)))
```

- 輸出：
```
--- 測試 3：完全相異內容測試 [預期：最差情況退化] ---
- A
- B
+ C
+ D
```
- 學習:
    - 邊界退化特性：當兩者毫無相似字元時，無法走任何成本為 0 的對角線，$D = N + M$。Myers 的時間複雜度退化為 $O((N+M)^2)$，搜尋範圍與傳統 DP 相仿
