### 什麼是高斯-賽德爾迭代法？
(1) 高斯-賽德爾迭代法（Gauss-Seidel Method）是數值線性代數中用來求解大型線性方程組 $Ax = b$ 的經典演算法，屬於標準的數值迭代法。特別適用於大型稀疏矩陣（Sparse Matrix）的系統（如偏微分方程離散化後的數值模擬）。
(2) 核心目標：從一組初始猜測值 $x^{(0)}$ 出發，透過逐步更新未知數的值，讓數值逐步逼近精確解。如果只用高斯消去法或直接求逆矩陣，時間複雜度高達 $O(n^3)$ 且巨型矩陣容易耗盡記憶體；而高斯-賽德爾法每輪迭代的時間複雜度僅為 $O(n^2)$，且能直接在原本的向量上做就地更新（In-place update）。
(3) 判定結果：
* CONVERGED（已收斂）：在指定迭代次數內，相鄰兩輪解向量的誤差小於設定的門檻值 $\text{tol}$，成功求得數值近似解。
* DIVERGED / REACHED_MAX_ITER（發散或超時）：達到最大迭代次數上限仍未能收斂，通常意味著係數矩陣不滿足收斂條件，數值可能發散或在區間內震盪。
(4) 矩陣表示與更新公式：
* 係數矩陣 $A$ 可以分解為對角項 $D$、嚴格下三角 $L$ 與嚴格上三角 $U$，即 $A = D + L + U$。
* 矩陣迭代形式為：$(D + L)x^{(k+1)} + Ux^{(k)} = b$
* 對於第 $i$ 個未知數，在第 $k+1$ 次迭代時的純量更新公式為：
$$x_i^{(k+1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{j < i} a_{ij} x_j^{(k+1)} - \sum_{j > i} a_{ij} x_j^{(k)} \right)$$
(5) 關鍵特色（原地更新）：
* 雅可比法（Jacobi）：必須等待整輪所有未知數計算完畢後才統一換新，需同時維護新舊兩組向量。
* 高斯-賽德爾法：只要前面算出了最新值 $x_j^{(k+1)}$，在同一輪計算後面的變數時就「立即套用」。這讓它的收斂速度通常比雅可比法快約一倍，也大幅節省記憶體。
(6) 收斂保證（充分條件）：只要矩陣滿足「嚴格對角優勢（Strictly Diagonally Dominant）」或「對稱正定（Symmetric Positive Definite, SPD）」，不論起始值設為什麼，演算法保證絕對收斂。

### 程式模組與演算法架構
高斯-賽德爾求解器主要由四個模組組成：

1. check_diagonal(A)（對角線檢查）
因為更新公式的分母為 $a_{ii}$，對角線元素絕對不能為 0。若發現對角線有 0，必須拋出異常或先進行列交換，避免發生除以零的錯誤。

2. in_place_update(A, b, x)（原地更新）
依序遍歷每個方程式 $i$：
- 將常數項 $b_i$ 扣除同行中其他變數的乘積項 $\sum_{j \ne i} a_{ij} x_j$。
- 因為是直接原地修改 $x[i]$，當算到第 $i$ 列時，前面 $j < i$ 的變數早已被替換成當輪最新值，天然實現了 Gauss-Seidel 的核心機制。
- 地雷點：計算總和時切記要跳過對角線項 $j = i$ 本身，扣除完後再除以 $a_{ii}$。

3. calculate_error(old_x, new_x)（收斂誤差判定）
使用無窮範數（$L_\infty$ 範數，即所有變數變動量的最大絕對值 $\max_i \vert{}x_i^{(k+1)} - x_i^{(k)}\vert{}$）來衡量解的穩定度。當最大變動量小於門檻 $\text{tol}$ 時，視為收斂。

4. solve_gauss_seidel(A, b, tol, max_iter)（主控迴圈）
設定初始向量（預設全為 0），迴圈執行更新步驟，記錄並印出每一步的誤差。若在上限步數內誤差小於指定門檻即宣告收斂並回傳結果；若超過上限仍未達標則判定未收斂。

### 測試
1. 測試 1：一般對角優勢方程組（驗證原地更新的收斂性）
* 測資：
$$\begin{cases} 4x_1 - x_2 + x_3 = 7 \\ 4x_1 - 8x_2 + x_3 = -21 \\ -2x_1 + x_2 + 5x_3 = 15 \end{cases}$$
* 程式碼：
```python
print("--- 測試 1：3x3 嚴格對角優勢方程組 [預期：成功收斂 (2, 4, 3)] ---")
A1 = [
    [ 4.0, -1.0,  1.0],
    [ 4.0, -8.0,  1.0],
    [-2.0,  1.0,  5.0]
]
b1 = [7.0, -21.0, 15.0]
solve_gauss_seidel(A1, b1, tol=1e-6)
```

* 輸出：
```
--- 測試 1：3x3 嚴格對角優勢方程組 [預期：成功收斂 (2, 4, 3)] ---
狀態: CONVERGED (已收斂)
總迭代次數: 10
變數解: {'x1': 2.0, 'x2': 4.0, 'x3': 3.0}
最後誤差 (L_inf): 9.7718e-08
```
* 學習:
    - 原地覆蓋的加速威力：觀察每輪的變數，第一輪算出來的 $x_1$ 馬上被帶進第二式算 $x_2$，收斂速度比各自保留舊值的雅可比法快非常多，只花了 10 輪就收斂到 $10^{-6}$ 的精度。
- 初始值不敏感：初始值即便全設為 0，只要矩陣滿足對角優勢條件，不管起點在哪都會像重力滑坡一樣穩穩掉進唯一解。

2. 測試 2：非對角優勢矩陣導致發散
* 測資：
$$\begin{cases} 1x_1 + 5x_2 = 6 \\ 4x_1 + 1x_2 = 5 \end{cases}$$

* 程式碼：
```
Pythonprint("--- 測試 2：對角線元素過小的發散矩陣 [預期：無法收斂 DIVERGED] ---")
A2 = [
    [1.0, 5.0],
    [4.0, 1.0]
]
b2 = [6.0, 5.0]
solve_gauss_seidel(A2, b2, tol=1e-6, max_iter=20)
```

* 輸出：
```
--- 測試 2：對角線元素過小的發散矩陣 [預期：無法收斂 DIVERGED] ---
狀態: DIVERGED / REACHED_MAX_ITER (未能收斂)
總迭代次數: 20
最後誤差 (L_inf): 1.0995e+12
```
* 學習:
    - 對角優勢的重要性：當 $\vert{}a_{ii}\vert{}$ 小於同一列其他元素的絕對值和時，迭代誤差每一步都會被放大（譜半徑大於 1）。從輸出可以看到誤差直接炸裂到 $10^{12}$。這提醒我們高斯-賽德爾法不能拿來盲目硬套，前置的列交換（Pivoting）至關重要。

3. 測試 3：對角線出現零的邊界條件
* 測資：第一式對角項為 0（即 $0x_1 + 2x_2 = 4$）
* 程式碼：
```
Pythonprint("--- 測試 3：對角線元素為零的異常檢驗 [預期：報錯拋出異常] ---")
A3 = [
    [0.0, 2.0],
    [3.0, 1.0]
]
b3 = [4.0, 5.0]
solve_gauss_seidel(A3, b3)
```

* 輸出：
```
--- 測試 3：對角線元素為零的異常檢驗 [預期：報錯拋出異常] ---
錯誤: 對角線元素 A[0][0] 為 0，無法進行除法運算。
```
* 學習:
    - 邊界防禦機制：除以對角線項是高斯-賽德爾法的物理極限。遇到對角線為 0 時程式必須有防禦性檢查主動攔截，否則會直接觸發 ZeroDivisionError 當機。在工程實務上，若遇到此情況需先調整方程組的排列順序。
